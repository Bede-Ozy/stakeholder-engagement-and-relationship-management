# Stakeholder Engagement & Relationship Management in the Civil Service

A premium, interactive **16-slide web-based presentation deck** engineered for public-sector leadership conferences, executive retreats, and senior administrative masterclasses.

**Theme:** *Mastering Administrative Procedures and Emotional Intelligence for Decision Making*  
**Audience:** Civil servants, directors, public-sector managers, administrators, and policy professionals.

---

## 🌟 Key Features

* **16 Executive-Grade Slides**: High-impact visual storytelling across stakeholder ecosystem mapping, power-interest analysis, active listening, negotiation, dispute resolution, the trust equation, Nigerian civil service context (OHCSF & SERVICOM), and the signature **5R Model**.
* **Animated Continuous Gradient Borders**: Distinct top and bottom accent runners flowing seamlessly left-to-right with glowing multi-stop gradients.
* **Living Dynamic Backdrop**: Ambient animated constellation network, breathing micro dot-matrix pattern, and administrative blueprint grid lines with smooth GPU acceleration.
* **Hover-Activated Top Navigation**: Auto-hiding executive header that smoothly slides down on hover and tucks away to maximize screen canvas.
* **Subtle Progress Dock**: A nearly transparent (see-through) bottom progress indicator that fully illuminates upon hover.
* **Fluid Fullscreen Zoom**: Instant transition to edge-to-edge canvas (`100vw × 100vh`) with no background distractions.
* **Executive Mode Toggling**: Seamless switching between **Executive Dark Navy** and **Template White** themes.
* **Comprehensive Speaker Notes & Sources**: Built-in executive talking points and citations accessible on demand without cluttering visual delivery.

## ⌨️ Presentation Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| **`→`** / **`Space`** / **`PageDown`** | Next Slide |
| **`←`** / **`PageUp`** | Previous Slide |
| **`Home`** / **`End`** | Jump to First / Last Slide |
| **`F`** | Toggle Fullscreen / Edge-to-Edge Canvas |
| **`S`** | Open / Close Speaker Notes Drawer |
| **`G`** | Open / Close Slide Grid Navigation Matrix |
| **`R`** | Open / Close Statutory & Research Sources |
| **`Esc`** | Close All Open Modals & Drawers |

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or serve it locally:

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```
